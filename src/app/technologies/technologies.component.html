Technologies Used

Frontend

We used Angular to create a dynamic and interactive user interface, styled with HTML and CSS. TypeScript ensures type-safe logic and efficient performance. Angular's modularity and component-based architecture made it easier to maintain and extend the UI. Additionally, responsive design principles were applied to optimize the user experience across devices

Backend

Flask serves as the lightweight backend framework, handling API requests and routing to connect the deep learning model with the frontend. Its simplicity and scalability enabled quick deployment of the application. We leveraged Flask's flexibility to seamlessly integrate the model, providing efficient data handling and routing capabilities.

Deep Learning

TensorFlow/Keras powers the predictive model for classifying images. It enables accurate training and inference for various classes. With its advanced features, we implemented a convolutional neural network to process input images. These tools ensured reliable predictions and facilitated integration with the backend for real-time analysis.
